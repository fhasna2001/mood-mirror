# MoodMirror

A tiny command-line mood journal that turns your recent moods into a
personal "weather forecast" — no libraries, just Python.

## Usage
python main.py

Log a mood, watch your ASCII mood chart build up over days, and check
your forecast (sunny/cloudy/rainy/stormy) based on your recent trend.

This is a fun self-reflection tool, not a substitute for professional
mental health support.
